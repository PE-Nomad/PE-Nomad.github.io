M1 · PMDC Motor

PMDC Motor: Current & Speed Control with a 4-Quadrant Chopper

motor와 load를 modeling한 뒤 inner current loop부터 outer speed loop까지 안에서 바깥으로 쌓았습니다.

  • PI current controller에 back-EMF feedforward compensation과 anti-windup을 더하고, bandwidth를 2배로 올렸을 때 settling이 빨라지는 것을 확인
  • current loop bandwidth는 switching frequency의 1/20, sampling frequency의 1/25 이하로, speed loop는 current loop의 1/5로 설계
  • PI vs IP speed controller: PI는 rise time이 짧지만 overshoot가 있고, IP는 overshoot 없이 느림
  • 4-quadrant chopper에서 unipolar / bipolar PWM의 worst-case current ripple을 손으로 계산하고 simulation과 비교

B.S. Thesis · Smart Grid Lab, Yonsei University THESIS

Grid-Forming ESS-Based Black Start for a Radial-Vulnerable 154 kV Substation: A Case Study of Jangyeon Substation

장연 변전소는 154 kV 송전선 2회선으로 연결돼 있지만 분기점 이후 공용 철탑 구간 때문에 사실상 방사형처럼 취약합니다. 이 구간에 고장이 나면 변전소가 고립되는데, 22.9 kV 배전선에 연계된 PV inverter는 대부분 grid-following(GFL)이라 스스로 전압을 세우지 못합니다. 22.9 kV bus에 grid-forming(GFM) ESS를 두고 black start가 가능한지 검증했습니다.

  • PSS/E static power flow로 장연 변전소가 고립돼도 주계통은 정상임을 확인해 문제를 local restoration으로 좁히고, 3φ fault로 short-circuit capacity 3369.75 MVA, Thevenin impedance 7.038 Ω, X/R 9.14를 추출
  • 이를 바탕으로 PSCAD/EMTDC에 주계통 equivalent source + RRL, 154/22.9 kV transformer, 부하, PV feeder, ESS로 구성된 EMT 모델 구축
  • t = 3.0 s 철탑 3φ fault 후 고립 상황에서 GFL은 PLL 동기를 잃고 70 MW / 75 MVar surge, 1.2 kA device current peak, 48~72 Hz 진동 끝에 붕괴
  • VSM + droop 기반 GFM ESS(20 MW, J = 0.01, D = 0.3)는 dead bus에서 전압을 세워 overshoot 없이 18 ms 만에 0.9 pu, 20 ms 만에 ±2% 안정, RoCoF 0 Hz/s로 10 MW 부하 복구
  • current limiting loop로 device current peak를 0.068 kA로 제한해 GFL 대비 약 1/17.6로 stress 감소

C1 · AC/DC COURSEWORK

Diode Bridge Rectifier: Ideal Calculation vs Non-ideal LTspice Model

230 V/50 Hz(시드니)와 220 V/60 Hz(한국) 조건에서 constant power load를 가진 single-phase diode bridge rectifier를 손계산하고, line inductance Ls = 1 mH를 넣은 LTspice 모델과 비교했습니다.

  • 정전력 부하를 output current source로 모델링하고 average output voltage, power, voltage ripple, efficiency 비교
  • Ls가 charging current pulse와 함께 LC resonance를 만들어 capacitor가 peak 이상으로 충전되는 현상 분석
  • ripple 3% 조건을 맞추려고 C를 300 µF → 1200 µF로 키워 ripple 35.9 V → 8.79 V로 줄이고, 그 대가로 sharp input current pulse 때문에 efficiency가 96.9% → 94.8%로 떨어지는 trade-off 확인

C2 · DC/DC COURSEWORK

SEPIC Analysis & Design: 30–60 V → 90 V, 20–30 W, CCM

입력 30~60 V를 출력 90 V로 바꾸는 SEPIC을 worst case 조건에서 설계했습니다. inductor ripple current와 capacitor ripple voltage를 D, Ts, Vo로 유도하고, 그 식으로 CCM과 ripple 3% 조건을 만족하는 L1, L2, C1, C2의 범위를 구했습니다.

  • fs = 100 kHz, D = 0.6~0.75, 부하 270~405 Ω의 worst case로 소자 최솟값 결정
  • VDS 30 V MOSFET에서는 출력이 108 V로 틀어져, Vin + Vo margin을 고려해 200 V급 MOSFET(IRFH5020)으로 교체
  • 출력 ripple 0.23 V(0.26%), C1 ripple 0.85 V(< 3%), L1·L2 모두 CCM 동작을 waveform으로 확인
  • gate charge, parasitic capacitance, Ron이 실제 duty와 출력 전압에 주는 영향 분석

F1 · ePWM AQ · DB · TZ

10 kHz Complementary PWM with Dead Time & Trip-Zone Protection

inverter leg 하나를 구동하는 complementary PWM을 register 값만으로 만들고, fault 시 출력을 차단하는 Trip-Zone 동작까지 실험했습니다.

  • TBCLK 150 MHz, TBPRD 7500, up-down count mode로 10 kHz를 만들고 DBRED·DBFED 150으로 dead time 1 µs 설정
  • POLSEL 4가지를 비교해, dead time 동안 두 출력이 모두 Low가 되는 AHC가 일반 gate driver에 맞다는 결론
  • count mode별로 duty는 같고 pulse 위치만 달라짐을 측정. inverter에 up-down을 쓰는 이유는 symmetric PWM과 주기 중앙 ADC sampling
  • GPIO12를 GND에 연결해 trip을 걸고, one-shot은 latch되고 cycle-by-cycle은 다음 주기에 복귀하는 것을 확인
